BenchLab

Status: Prototype and usability test in progress

A testing simulator that runs in the browser. It is the public twin of the test-platform work I do at Baxter, rebuilt from scratch with nothing proprietary: the workflow is real, the device under test is simulated.

BenchLab is being built as coursework for WGU's prototyping sequence. The current prototype is in usability testing now; the findings decide what the next version changes.

What it does

  • Compose a test in a visual builder, step by step
  • Run it against a simulated device and watch it execute
  • Get a traceability report tying each step to its requirement
  • An agent layer turns plain-English protocols into executable test steps
